# Realiza documentation

Four independent private repositories owned by realizakitty:

- [realiza_web](https://github.com/realizakitty/realiza_web): React mobile/desktop website.
- [realiza_admin](https://github.com/realizakitty/realiza_admin): administration and permissions.
- [realiza_server](https://github.com/realizakitty/realiza_server): Go/Gin/MongoDB API.
- [realiza_docs](https://github.com/realizakitty/realiza_docs): product specifications, PDFs, design and operations.

See PRODUCT_REQUIREMENTS.md, DEPLOYMENT.md, and the included English pitch deck and whitepaper PDFs. Runtime secrets, SSH private keys, database contents and generated build output are excluded.
